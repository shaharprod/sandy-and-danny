# מועדון הצביעה של סנדי ודני · Sandy And Danny Coloring Club

Free coloring pages from every episode of the Sandy And Danny series (Hebrew + English).

- Hebrew episode link: `https://shaharprod.github.io/sandy-and-danny/?e=1&lang=he`
- English episode link: `https://shaharprod.github.io/sandy-and-danny/?e=1&lang=en`
- `pages/` holds the coloring pages (black line art on transparent background, 1600×900), made from each episode's frames.
- `qr/` holds the verified QR code for each episode and language.

Page 1 of every episode is always free. No sign-up, and no data is collected from children.
